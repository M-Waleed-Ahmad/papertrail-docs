# Quick manual test checklist

## Import

1. Import `product-launch-brief.md` and confirm headings, bold text, italic text, and both list types appear correctly.
2. Import `customer-interview-notes.txt` and confirm the paragraphs remain readable.
3. Refresh each imported document and confirm the content remains.

## Editing

1. Rename a document.
2. Add bold, italic, underline, a heading, and a list.
3. Wait for the Saved status, then refresh.

## Sharing

1. Sign in as the owner and share a document with the collaborator account.
2. Sign in as the collaborator and confirm the document appears under Shared with me.
3. Edit the document as the collaborator and refresh.
4. Remove access as the owner, then verify the collaborator can no longer open it.
